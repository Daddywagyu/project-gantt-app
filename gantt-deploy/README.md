# Project Gantt App

React + Vite + Tailwind project wrapping `ProjectGanttApp.jsx`.

## Run locally
```
npm install
npm run dev
```

## Deploy to GitHub Pages
1. Push this folder to a new GitHub repo (branch `main`).
2. In the repo: **Settings → Pages → Source → GitHub Actions**.
3. Push a commit (or re-run the "Deploy to GitHub Pages" workflow under the **Actions** tab).
4. The live URL appears under **Settings → Pages** once the workflow finishes
   (usually `https://<username>.github.io/<repo-name>/`).
